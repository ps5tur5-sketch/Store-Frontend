# Изменения интерфейса

Продолжение первого этапа `1baa8f3`: Vue 3, компоненты, Vite, nginx и отдельный Docker Compose сохранены.

| Область | Изменение для пользователя |
| --- | --- |
| Витрина | Новый адаптивный дизайн, локальные обложки, поиск/фильтры/сортировка, сравнение продавцов и цен |
| Аккаунт | Явная регистрация покупателя/продавца, общий вход, «Стать продавцом», переключение «Купить / Продать» |
| Корзина | Разные продавцы и партии одного товара отдельными строками; расчёт и наличие из API |
| Оплата | Баланс, СБП, USDT, отказ/повтор, восстановление платежа после перезагрузки |
| Покупатель | Составной заказ, прогресс выдачи/возврата, полученные ключи, отзывы, история и чат |
| Деньги | Пополнение, возвраты на баланс, тестовый вывод на карту/USDT и история заявок |
| Продавец | На первом экране каждый ключ со своей ценой и сохранением; отдельная публикация ключа |
| Массовые цены | Распределение имеющихся 1000 ключей по партиям 200/400/400 без повторной загрузки |
| Отчёт продавца | Покупатель, исходная цена продажи, возврат, закупка, доход и прибыль; страницы истории |
| Репутация | Проверенные отзывы, объяснение красного флага, доказательства с сервера |
| Администратор | Баны/разблокировки, возвраты/отзыв ключа, обращения, склад, резервы, платежи и сверка |
| Проверки | Семь сценариев Chrome, размеры 360/390/768/1440, CI сборки |

Frontend отображает backend-контракты: не выдумывает баланс, доступность, прибыль, рейтинг, возврат или цену. Сервер проверяет каждое действие независимо от состояния формы.
